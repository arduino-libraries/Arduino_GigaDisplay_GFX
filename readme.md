 # 🎨 Arduino_GigaDisplay_GFX Library

The **Arduino_GigaDisplay_GFX** library is a layer library for using methods from the [Adafruit GFX graphics library](https://github.com/adafruit/adafruit-gfx-library). It is specifically developed for the Arduino GIGA Display Shield and the Arduino GIGA R1 WiFi board.

It can be used to draw anything from single pixels to advanced geometrical shapes, and supports printing text and values with configurable font sizes.

⚠️ **Core Compatibility:** This library requires version **4.0.6 and above** of the standard [Arduino Mbed OS Giga Boards platform](https://github.com/arduino/ArduinoCore-mbed). It is also fully supported by the [Arduino Zephyr Boards platform](https://github.com/arduino/ArduinoCore-zephyr).

## Supported Hardware

| Board | Shield Supported | Default Resolution |
| --- | --- | --- |
| Arduino GIGA R1 WiFi | Giga Display Shield | 800 x 480 |

📚 To get started with this library and the shield, please refer to the [GIGA Display Shield GFX Guide](https://docs.arduino.cc/tutorials/giga-display-shield/gfx-guide).
